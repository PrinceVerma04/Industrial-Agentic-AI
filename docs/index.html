Capabilities

Five requirements, met by execution — not slides

Each capability below is a working code path in the repo, not a design doc.

🧩

Domain portability

The entity/relation schema is a YAML ontology pack, not hard-coded classes — point it at a new industry without touching code.

→ config/ontology.yaml
🧭

Automatic model routing

A declarative manifest + VRAM-aware LRU manager picks the right local model per task and swaps under a fixed memory budget — every decision logged.

→ config/models.yaml, app/router/
🤖

Agentic tasks end-to-end

A Plan → Execute → Critique → Synthesise loop that produces real .docx/.pptx/.xlsx artifacts, not just chat text.

→ app/agent/loop.py
🛡️

Sandboxed code execution

Generated code runs inside a network-isolated namespace, verified before its output is trusted.

→ app/tools/sandbox.py
🖼️

Multimodal understanding

Scanned inspection sheets are rasterised, OCR'd on CPU, and read by a local vision-language model for handwriting and diagrams.

→ app/ingest/pipeline.py
🔒

Proof of no external calls

A live egress monitor, an on-demand canary check, and a hash-chained audit log — sovereignty as a measurement, not a promise.

→ app/sentinel/

Two ways to ask

Run agent vs. Retrieve only

The workbench's dashboard exposes both — here's what each one actually does, and when to reach for it.

🤖 Run agent POST /ask

The full agentic pipeline. Plans a sequence of tool calls, executes them, critiques whether the goal was met, retries if not, then writes a cited, synthesised answer.

  • Best for real questions and drafting tasks
  • Can generate documents (.docx/.xlsx)
  • Slower — multiple LLM round-trips
  • Refuses rather than hallucinates when nothing relevant is found
Use it when you want a finished answer or artifact, not just raw matches.

🔎 Retrieve only GET /search

Skips LLM synthesis entirely. Auto-selects a retrieval mode (vector, local, or graph traversal) and returns the raw evidence — matched nodes, community summaries, and cited passages.

  • No reasoning step, so no hallucination risk
  • Fast — a single retrieval call
  • Shows exactly what's indexed and retrievable
  • Good for verifying a fresh index before trusting an answer
Use it to sanity-check the evidence, especially right after re-indexing new documents.
